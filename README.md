# 🛒 BazarDor — বাজার দর

BazarDor is a responsive web application for viewing daily market prices of essential products in Bangladesh.

## 🔗 Links

* **Live Website:** https://bazar-dor-web-app.vercel.app/
* **GitHub Repository:** https://github.com/asad4405/bazar-dor-app

## 🛠️ Technologies

* Next.js
* React
* TypeScript
* Tailwind CSS
* DaisyUI
* BetterAuth
* React Hot Toast
* REST API
* Vercel

## ✨ Features

* Responsive design
* Product price listing
* Price increase and decrease section
* Product category filtering
* Product sorting by price
* Product details page
* Market-wise product prices
* User registration and login
* Google and GitHub authentication
* Protected routes
* User profile update
* Toast notifications
* Loading skeleton
* Custom 404 page
* Bengali UI and numerals

## 🔌 API

**Base URL:**

`https://api.api-store.workers.dev/api/bazardor`

**Endpoints:**

* `/products`
* `/products?category=chal`
* `/products/1`
* `/categories`
* `/categories/chal`
